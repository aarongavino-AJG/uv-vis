# Activity 02 — UV–Vis Spectroscopy

Analysis of methylene blue and methyl orange using the particle-in-a-box model.

## Files

- activity02_notebook_gavino_aaron.ipynb — analysis notebook
- data/ — original export, individual spectra, and summary CSV
- figures/ — generated plots
- lab_report_activity02-2_gavino_aaron.pdf — report

## Setup and execution

Requires Python and Git.

```powershell
git clone https://github.com/aarongavino-AJG/uv-vis.git activity02-uvvis
cd activity02-uvvis
python -m pip install numpy pandas matplotlib jupyterlab
python -m jupyterlab
```

Open activity02_notebook_gavino_aaron.ipynb and select Restart Kernel and Run All Cells.

Keep the data and figures folders beside the notebook.
